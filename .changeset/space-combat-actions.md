- Added the `ship-action` item type and roll kind: starship manoeuvre and extended actions (Core Rulebook Ch. VIII) now roll through the shared funnel as a combined test — the performer's skill plus the ship's ability shown as a visible breakdown row.
- Ship actions resolve the performing Explorer's trained skill (owned specialisation preferred; a trained bare Pilot stands in at the untrained-specialisation −10), and fall back to the ship's crew quality when no helmsman performs the action.
- Added the Elite (60) NPC crew quality to the ship crew ladder (Core Rulebook Table 8-9).
- Starships track ship-combat turn state: turn-scoped modifier flags (expired at the flagged ship's own Strategic Turn start — the combat tracker's turn change drives the expiry and the previous-turn crew-loss rotation, with persistent Repel Boarders), the boarding pair, revealed components, Silent Running and the previous turn's crew losses.
- Ship salvos read that turn state as visible modifier rows on BOTH sides: the target's Evasive Manoeuvre −10 against the shot, the firing ship's own Evasive −10, the Come to New Heading penalty and Lock on Target's +5 for the weapon it names.
- Firing under Silent Running now clears the flag and warns the shooter they betrayed their position.
- A boarded ship refuses ship-weapon salvoes with an explicit warning; extended actions (Emergency Repairs) stay allowed.
- Added the starship initiative path (1d10 + the Detection tens digit, Core Rulebook p212-213) to the initiative roll: token context menu and the ship sheet's Combat tab roll it for owned ships, the card shows the Detection row of the breakdown, and the result is assigned to the ship's combatants.
- Ship combat covers every printed action row: the Core Rulebook Table 8-10 Manoeuvres (Adjust Bearing, Adjust Speed, Adjust Speed & Bearing, Come to New Heading, Disengage, Evasive Manoeuvres) and the Table 8-11 Extended Action rows surface on the Ship Combat tab (see below), each carrying the printed test, difficulty token and the verbatim book prose; Stern Chase stays deferred (Exploration Challenge machinery) and Emergency Repairs remains the ship-repair path.
- Pilot acquires as the book's Skill Groups rule requires: the Personal, Flyers and Space Craft groups sit alongside bare Pilot as separately pickable skills in the lists players choose from.
- A ship whose Detection field is missing fails loudly instead of silently.
- Manoeuvre Actions now run their book extras (Core Rulebook pp213-215, 218): the default Manoeuvre is a free informational chip (no test), Come to New Heading writes the −20 BS penalty flag for the firing turn, and Evasive Manoeuvres write the −10 flag the salvo reads on BOTH sides; a failed manoeuvre writes no flag.
- Disengage's 8-VU gate is a GM prompt with manual distance entry (never an automatic refusal), the card posts the opposed side's Detection+Scrutiny requirements (opposed side rolls manually), and the no-re-engage / no-Stern-Chase notes ride the roll.
- A boarded ship refuses Manoeuvre Actions with an explicit warning while extended actions stay allowed.
- Every manoeuvre card carries the GM facing note derived from the hull class (transports/raiders/frigates 90°, other hulls 45°); v1 enforces nothing.
- While Silent Running stands, related tests carry a visible one-difficulty-step (−10) row and the default Manoeuvre's chip states the Ordinary (+10) requirement it demands (Core Rulebook p218).
- The ship initiative card carries the combat-start manual rulings as note lines (Surprise +20 in Round 1; the NPC vessel 3-actions-per-Strategic-Round cap) and a Boarding banner for boarded ships — visibility only, no automation.
- Implemented the remaining Table 8-11 Extended Actions as ship-action handlers (Core Rulebook printed pp216-218): Focused Augury fills the target's revealed-components ladder (essentials → weapons → auger/shields → all) and Active Augury scans with the +5 VU/degree range and Silent Running detection; Aid the Machine Spirit, Lock on Target, Prepare to Repel Boarders! (persistent) and Put Your Backs Into It! land their +5/+10 bonuses as visible turn-state flags; Flank Speed notes its per-degree movement and inflicts the immediate Engines Crippled critical on a hard fail; Hold Fast! (gated on Air of Authority, a Willpower characteristic test) and Triage cancel the PREVIOUS turn's Morale/Crew Population damage through the one-turn loss memory; Disinformation, Hail the Enemy (prompted over the character's Interaction skills) and Jam Communications post their book-cited manual notes.
- Hit and Run: the raiding craft test rides the target's Turret Rating as a visible −10/point row, the craft is shot down on a 4+ degree failure, the opposed Command stays manual with the boarding bonus rows on the card, and a manual win applies the 1d5-twice critical pick + Hull Integrity per degree, with the crew loss following as normal.
- Critical-hit component prompts are now gated to the target's revealed components: a ship that has never been Focused-Augury-scanned offers no component picks (with a loud note), replacing the all-knowing stand-in.
- Added the ramming action machinery (Core Rulebook p215): a Hard (−20) Pilot (Space Craft) + Manoeuvrability combined test within 1 VU (manual distance entry) whose success deals the hull-class die plus the ramming ship's prow armour to the defender — void shields ignored, both ships take Hull Integrity and 1:1 Crew/Morale losses, and the ramming ship takes the defender's Armour + 1d5 back into its own prow.
- Added the boarding-machinery rows (Core Rulebook p215): the boarding lock writes the boarded pair onto BOTH ships (Manoeuvre and Shooting denied both sides, last in initiative), break-free runs the Hard (−20) combined test at the ship's turn start (success clears the pair on both ships; failure sets the −20 on the subsequent opposed Command), the boarding turn presents the opposed-Command bonus rows as visible contributors (+10 per full 10 points of Crew Population and Hull Integrity difference, turret rating +10/point both directions, Repel Boarders values), the winner's per-degree pick (1d5 Crew Population + 1d5 Morale, or 1 Hull Integrity that drags Crew/Morale 1:1) applies through prompts, and the losing ship rolls the rout d100 vs current Morale — equal or lower keeps fighting, higher routes: an NPC vessel surrenders, the explorers' vessel posts the grim-choice card.
- The Ship Combat tab is the actions' sheet face now (Core Rulebook Tables 8-10/8-11): every printed action row renders as a roll chip grouped Manoeuvre / Ramming-Boarding-machinery / Extended, labelled with its printed test and difficulty, with the default Manoeuvre as the FREE informational button; every chip enters the ship-action roll kind with the picked helmsman (picker on the tab, sheet-persisted, crew-quality fallback when unset) — and the machinery rows with their own prompts (Break Free / Rout) fast-forward the shared dialog (skipDialog).
- The Ship Combat tab renders the turn-state surfaces: active turn-flag chips with their signed values and expiry notes ("next own turn" / persistent for Repel Boarders!), the Silent Running toggle (posted state card; firing still reveals), and the boarding banner with the locked partner, the −20 failed-break-free note, the break-free button and the opposed-Command manual reminder carrying the computed bonus rows this ship and the enemy read.
- Added Battlefleet Koronus ship ordnance: a `ship-ordnance` item type carrying the printed torpedo-warhead, guidance-system and attack-craft stat columns (Table 1-1, p.8; Table 1-3, p.14), with the machinery entering through the shared ship-action kind — Launch Torpedoes books the salvo + the `torpedo-run` turn flag, Torpedo Run resolves the travel/attack with BFK's turret shoot-down (+5 per Turret Rating, 1 hit + 1 per two degrees) and per-torpedo Terminal Penetration damage (torpedoes and bombers ignore void shields), and Bombing Run / Assault Boat Run / Attack with Fighters roll the printed Command + Craft Rating strikes.
- Ordnance launches always spend stores through the single ordnance decrement helper; empty stores refuse loudly.
- A live Battlefleet Koronus torpedo salvo now surfaces on the Ship Combat tab's turn-state strip as a translated chip carrying the travelling torpedo count.
- Cancelling any boarding-rout prompt (opposed-Command winner, winning degrees, the winner's per-degree pick) posts a cancelled-state note card — the board turn stands UNRESOLVED on the log, never a silent stop.
- The Ship Combat tab's turn-flag chips name the boosted stat on Aid the Machine Spirit flags (no dangling empty target), and the Rout chip's test slot reads the manual-machinery label instead of the raw machine key.
