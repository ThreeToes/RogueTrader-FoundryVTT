- Added the `ship-action` item type and roll kind: starship manoeuvre and extended actions (Core Rulebook Ch. VIII) now roll through the shared funnel as a combined test — the performer's skill plus the ship's ability shown as a visible breakdown row.
- Ship actions resolve the performing Explorer's trained skill (owned specialisation preferred; a trained bare Pilot stands in at the untrained-specialisation −10), and fall back to the ship's crew quality when no helmsman performs the action.
- Added the Elite (60) NPC crew quality to the ship crew ladder (Core Rulebook Table 8-9).
- Starships track ship-combat turn state: turn-scoped modifier flags (expired at the ship's next Strategic Turn, with persistent Repel Boarders), the boarding pair, revealed components, Silent Running and the previous turn's crew losses.
- Ship salvos read that turn state as visible modifier rows on BOTH sides: the target's Evasive Manoeuvre −10 against the shot, the firing ship's own Evasive −10, the Come to New Heading penalty and Lock on Target's +5 for the weapon it names.
- Firing under Silent Running now clears the flag and warns the shooter they betrayed their position.
- A boarded ship refuses ship-weapon salvoes with an explicit warning; extended actions (Emergency Repairs) stay allowed.
- Added the starship initiative path (1d10 + the Detection tens digit, Core Rulebook p212-213) to the initiative roll: token context menu and the ship sheet's Combat tab roll it for owned ships, the card shows the Detection row of the breakdown, and the result is assigned to the ship's combatants.
- A ship whose Detection field is missing fails loudly instead of silently.
- The ship initiative card carries the combat-start manual rulings as note lines (Surprise +20 in Round 1; the NPC vessel 3-actions-per-Strategic-Round cap) and a Boarding banner for boarded ships — visibility only, no automation.
