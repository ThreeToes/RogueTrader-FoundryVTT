# Rogue Trader System for FoundryVTT

An **UNOFFICIAL** system for playing Rogue Trader on [Foundry VTT](https://foundryvtt.com/).

It provides support for **character sheets and rules only**, game content
should be drawn from official source books.

This project was forked from the [Dark Heresy 2E](https://github.com/Vendare/DarkHeresy2E-FoundryVTT)
system, though has been more or less completely rewritten to use the newer
features of Foundry.

## Install

This module still isn't quite ready, so if you really want to install it,
you can figure that out yourself.
